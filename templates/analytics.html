DBMS Project Architecture & Viva Highlights

How SQL Joins, Views, and Triggers function in this system

LEFT OUTER JOIN

Combines trains with bookings. Even if a train currently has 0 bookings, it still appears in the report with 0 revenue instead of being excluded.

SQL Views (CREATE VIEW)

Encapsulates complex multi-table joins into reusable virtual tables: v_booking_manifest and v_train_occupancy_report.

Automated SQL Triggers

trg_decrement_seat_on_booking and trg_increment_seat_on_cancellation enforce seat inventory integrity automatically inside the SQL engine.
